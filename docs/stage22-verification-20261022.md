# 阶段22：复杂资料与检索覆盖

## 交付内容

- 局部检索保持原有候选、切片和送达数量；另加显式顺序分批整理，固定索引与文件范围，不按问题关键词删去记录。
- 本地读取计划和分页原文查看；引用支持查看前后提取块。PDF保留真实页码，表格保留行/单元格位置；长行按Unicode字符切分并记录区间，不重建跨页表格或推断业务关联。
- 分批可附实际表格首条记录或明确Markdown标题作为上下文；首条记录不认证为表头，不继承虚构列名。主片段每批最多6×700字符，加上下文不超过5500字符。
- 输入送达与输出可用范围分开记录，1至8批、总预算256至50000 Token。每批输出上限仍为1200 Token；预算不足、格式无效、截断、失败或用量未知均停止后续请求。没有自动修补或付费重试。
- 继续整理是用户明确触发的新任务，固定原问题、版本和文件范围。最终协议v2从首个未完成批次继续；已送达但响应无效的批次不会被跳过。界面明确重发会另计调用，前次记录不变。续读从保存的旧批次定位，不修改旧覆盖数据。
- 批次结果、原始请求/输出、结构检查和覆盖记录独立保存；导出保留批次列和覆盖范围，不自动合并去重或补写统一结论。未确认收到的失败请求仅保留在批次尝试记录，不作为确认送达证据导出。
- 一并修正调用汇总中重排输出Token及失败响应已知Token分量的保留；嵌入分批之间检查停止标志，避免停止后继续发送下一批。
