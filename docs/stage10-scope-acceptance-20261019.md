## 修复内容

- `analysis_scope.py` 从当前任务的明确指令提取已知方法（Wilson、Wald、Clopper-Pearson、Agresti-Coull、Fisher），不由历史或网页增加权限。支持明确多方法和局部否定。规划移除额外方法任务，共享 session 中约定更新后代码工具同步使用。
- `run_python` 在创建运行文件/启动进程前检查 AST 标识、导入及带计算参数的输出标签，避免只把 Wald 名字写在 `print` 字符串里而绕过检查。注释、纯文本和否定说明不等同计算。这不是未命名数学表达式的语义识别，也不是执行沙箱。
- 报告完整稿、追加和 patch 在保存/审稿前核对长度与额外方法结果；正文检查遍历同句每次方法提及，表格也检查。区分 `(0,1)` / `[0,1]` 概率定义域与实际区间结果，避免把概念解释误拒绝。失败保持旧文件及检查结果。
- 超限反馈给出实际差额和最长句，建议整稿缩减并留余量，减少微删后反复超限。60% 是草稿建议，原硬上限未变；不自动截断报告。默认简述正文软目标仍为 500 可见非空白字符，超过 1000 要提交至少 20 字符的扩展理由，理由不自动认证范围合规。
- 审稿先删除未要求的分析，不要求用更多方法/模拟/图表补救可选内容。离线题不伪造未读取的文献，未知抽样与独立性不能补为事实。
- 费用变化按旧基准的费用权重解释。由当前数据生成的“输入减半、输出不变”情景标为反事实，不当作真实历史；有限模板拦截用本次权重错误推导翻倍总费用的说明。数值检查规范化 LaTeX 乘除符号，避免对正确算式截取后缀误判。
- 条件引述如“判断‘A 最稳定’需要 B、C 数据”不作为赢家断言；保留已认定、转折肯定等反例。离线评估支持模块级 pytest selector。
- 默认 DeepSeek 模型显式使用 `deepseek-flash`，发送 `thinking: disabled`；每次模型调用记录请求名和返回名，旧日志缺项保持未知。默认 API Key 仅来自项目 `.env`，缺失不回退全局环境。未修改 Windows 全局 Key。
