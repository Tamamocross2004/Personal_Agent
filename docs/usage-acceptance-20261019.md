# 调用与成本统计 · 2026-10-19

本次仅交付桌面任务级用量与费用统计，不开展阶段12、恢复功能或其他扩展。使用入口为右侧“用量”及回答下方的调用/金额按钮，配置入口为运行设置中的“费用估算费率”。

## 实现与口径

- 汇总已返回的 `llm_call` 与明确失败的 `llm_error`，分为规划、研究、审稿及其他。未返回请求尚不计入已记录调用。LLM客户端在实际请求前累计尝试数，含tenacity重试；成功和失败均可记下尝试增量。新事件只记录失败类型，不记录可能含密钥的原始异常文本。
- 输入、缓存命中/未命中、输出分别汇总，命中率按有缓存拆分的输入加权，不取各次百分比平均。新增用量/缓存元数据存在标记，区分真实零值和缺失。
- 使用Decimal按人民币/百万token三档费率计算，不将等效token预算权重当作价格。无费率、身份不明、缺少计费用量或需要但缺少缓存拆分时不报零；展示未计价次数和已知部分。
- Flash固定高峰参考2/0.04/8元、空闲参考1/0.02/4元（依次为未缓存输入/缓存输入/输出），来自2026-10-19核对的[官方价格页](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)。不自动判断时段或节假日；其他模型可自行配置，不猜价格。
- 在任务提交时冻结匹配到的费率。已有快照不随新配置变化；无快照的历史任务明确显示按当前配置回溯估算。费率本机持久化，关闭估算不删除已有快照。
- 后端增量读取日志，不依赖前端最近400个事件。损坏/超长行、未完整末行及缺少结束记录有提示；日志缺失不当作零用量。旧日志未记录的失败/重试不可恢复，尝试数显示下限。

范围是单个任务已记录的模型token估算，不是平台实际扣款、账户余额或项目全量账单。不含未返回用量、工具服务费用、账户优惠或未索引任务，无法据此精确核对账户累计账单或识别每次调用所用Key。
