# 阶段31：先规划字段意图再整理

日期2026-10-23；基线d38f1ec（stage-30）；复核者coding_assistant，非独立人工审稿。阶段12仍未验收。工程、已知回归、新材料和模型语义边界分别报告。

## 为什么改流程

阶段30只修改生成说明，曾将属性缺失正确改成unknown，但又把应原样摘录的标签文字改成unknown。继续添加某个措辞的规则会扩大误判，因此本阶段增加独立规划步骤：模型只看用户问题，先逐字段决定用户要属性事实还是文字本身。随后资料请求明确携带这份意图，不混入答案或作为新证据。

规划使用独立小型Schema，字段名与依据原句须逐字存在于问题，禁止重复及未请求字段；没有向规划请求发送资料、对象答案或验收预期。模式的语义解释仍由模型给出，quote检查只能证明文字存在，不能认证模式选择正确。空字段列表允许保留原有自由问答，不编造字段。

新规划请求、原始响应、结束原因、用量和状态先后持久化。规划失败、截断、字段/原句无效或用量未知时停止，不修补、不重试；取消可阻止规划请求或规划后的资料请求。规划输出最多1024 Token并受原单次额度和剩余总预算约束，实际调用计入同一个上限和预算。续读固定原问题并复用已有规划，不重发原答案或再规划一次。

桌面持续整理中默认勾选，可关闭；普通模式不增加调用。CLI/API显式`plan_fields`/`--plan-fields`启用。生成说明版本4仅增加按字段意图解释的说明，回答v3类型、接收Schema与原句/来源检查不变。没有未知值关键词表、对象规则、数值不等自动判冲突或输出修补。

## 调用前固定的真实诊断

[计划](stage31-live-plan-20261023.json)在首次嵌入前保存LF原字节，包含资料SHA、期望状态/值/来源、运行快照、问题和预算。与阶段30是不同的流程实验，不扩写或重评阶段30计划；上限20次聊天、4次嵌入、70000已知Token。使用项目.env中的deepseek-flash、默认非思考、零重试。

| 案例 | 字段匹配 | 边界 |
|---|---:|---|
| 已知状态回归，启用规划 | 10/10 | 完整复制原CSV和原问题，沿用原预期；是开发回归，不是独立保留集 |
| 新8行双字段，不规划 | 16/16 | 同模型、问题、固定批次、输出和预算 |
| 同一份新资料，先规划 | 16/16 | 包含额外规划调用和更长输入；本配对没有显示质量增益 |
| 同设备同检测时刻互斥状态 | 2/2 | 明确conflict、可比条件成立 |
| 同一瞬时采样编号的不同电压 | 2/2 | 明确conflict、可比条件成立 |
| 可同时支持的部分压缩格式列表 | 2/2 | difference，没有误判conflict |
| 不同采样日期的液位 | 2/2 | difference，必要共同条件未成立 |

字段匹配要求原值、状态及对应文件SHA/记录位置同时一致，原预期没有调整。已知回归中，属性“不详”被保留为unknown，标签“未知”“未定”按用户要求保留为stated文字，零和实际空白没有被混同。新资料扩展了属性缺失与标签文字措辞；全部输出通过当时的原v3结构/引用检查且正常stop，没有截断或失败批次重试。

状态资料使用每批3个主片段、输出2400 Token；已知回归总预算16000，新资料两组均22000，规划包含在各自预算内。关系题用输出1200和预算14000。这些是显式诊断配置，不是桌面默认值；默认输出1200或较小预算可能需要更小批次、续读或用户显式调整设置。

四组关系正文由coding_assistant对照原文检查；双方对象、时间/条件及理由分别保留。程序仍没有语义判定器。规划在“支持压缩格式”案例给出了verbatim模式，其原问题依据真实，但这种解释并不证明用户意图分类已普遍可靠；最终关系结果仍正确保留为可兼容差异。

实际18次聊天（含6次规划）、2次嵌入、0次重排、52838已知Token，未知用量0；人民币总额未定价。新资料没有规划时也全匹配，规划增加了成本，不能凭已知回归10/10宣称通用正确率提升。阶段30的失败记录、18行部分完成和本阶段全部原始响应均保留。

## 工程复检及限制

新增检查覆盖仅问题规划、字段名/原句/重复校验、元数据进入实际请求、同预算和调用上限、失败/未知/截断停止、停止请求的两个边界、续读复用及原任务不变。初轮38项定向检查通过；最后补充的停止/失败边界由完整回归验证，数量和结果见[机器记录](stage31-evaluation-20261023.json)。

隔离Electron使用明确假服务，验证规划加15次资料调用共16次仍在10000总预算内，规划不收到原文、实际请求携带意图、原问题/范围/费用及来源不变；原规划与依据可展开查看。初次截图发现复选框受旧标签样式影响，修正布局后重新构建和检查，初次截图保留。构建成功，仍报告主JS包超过500 kB的构建警告，没有关闭用户现有应用。

真实诊断之后只补充了规划调用前的停止检查、规划返回后的停止状态及空范围跳过规划，没有改生成说明、问题、资料、判定预期或答案；实际快照和最终源代码SHA分别保存。预算和调用上限仍可使资料部分完成，不增加额度来掩盖此边界。字段规划自身可能理解有误；这些有限材料通过复检不代表所有自由问答、所有模型或阶段12已通过内容验收。
