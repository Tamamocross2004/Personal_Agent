## 功能与使用

新任务通过CLI或桌面正常启动，即自动保存`.agent-checkpoint.sqlite3`。SQLite事务、FULL同步、状态校验和、任务文件哈希及本机进程锁共同保护已提交边界。保存结构化JSON，不加载pickle或可执行对象。旧trace不是检查点，旧任务没有此文件就不能直接恢复。

status中的status字段是最后持久化状态；例如进程被杀后仍可能显示running。当前能否恢复以resumable及reason为准，它们会检查实际进程锁和产物，不把旧running标签当活进程。

在项目根目录运行：

```powershell
# 只查看条件，不调用模型
.\.venv\Scripts\python.exe -m agent.resume status "任务目录"

# 请求正在运行的任务在当前调用返回后停止
.\.venv\Scripts\python.exe -m agent.resume stop "任务目录"

# 显式恢复，会按后续实际需要调用模型并计入原任务额度
.\.venv\Scripts\python.exe -m agent.resume run "任务目录"
```

优先使用协作停止而非杀进程：当前模型返回若已保存，可以恢复处理该回复。Ctrl+C或强制停止发生在请求中间时，可能只能得到“需核对”，不能确认服务端是否已执行或计费。

桌面重启后加载新后端与构建文件，选中任务，右侧显示“检查点恢复”、累计步数/token/审稿次数及恢复条件，满足条件时点击“从检查点恢复”。排队状态是“等待恢复”，仍是同一个任务ID、目录及费率快照。恢复后事件连接重新读取累计记录，不重复累计旧事件。应用关闭或服务重启仍不会自动恢复或重新发起研究。

## 可以继续与需要核对的边界

| 边界 | 首版行为 |
|---|---|
| 首次规划前，尚未派发请求 | 可继续规划 |
| 主循环回复已完整保存 | 复用该回复和已记录用量，不重发同一模型请求 |
| 工具批次及后处理已提交 | 从下一步继续，已完成工具不再执行 |
| 报告已保存、审稿尚未派发 | 继续原报告审稿，不重复写报告 |
| 审稿已提交 | 保留摘要、版本绑定及次数，不重复审同一版本 |
| 最终结果已保存，本地收尾/记忆尚未完成 | 只继续本地收尾；记忆依task_dir事务upsert，重复执行不新增重复记忆 |
| 模型请求结果或用量未知 | 需核对，不重发请求、不假设用量为零 |
| 工具执行中或工具批次尚未完整提交 | 需核对；已保存的结果/证据保留，不自动重放批次 |
| 外层工具线程超时 | 停止派发后续操作，需核对；超时不证明后台副作用结束 |
| 规划/审稿/强制收尾只返回但尚未提交结果 | 记录已知用量，需核对，不重复获取额度 |
| 已正常完成，或额度/步数耗尽后已完成收尾 | 不能恢复成新额度；只能另建明确的新任务 |

首版以完整工具批次为自动恢复边界，尚未支持批内逐调用续跑。进入强制收尾后的未提交中断也不自动继续，防止反复恢复获得额外收尾调用。对需核对状态没有强制跳过或人工裁决后原地续跑入口；需查看已有产物和记录后另定操作，不能手改计数器冒充恢复。

## 保存和一致性

- 保存原问题、任务约定、完整模型上下文、截断续写/空回复状态、原计划文件、工具重复保护及错误反馈、报告完整性、上次审稿/版本、累计步数/原始与等效token/审稿次数和上下文压缩回差。
- 保存网页缓存、笔记、失败抓取、证据ID/原文/哈希及历史背景；恢复不重新召回历史或自动刷新缓存，不把历史或未送达网页扩为已读证据。
- 恢复固定沿用原公开运行配置与模型，设置面板/`.env`的新预算不会覆盖该任务。实际构造的不同模型、工具schema或参数会被拒绝；API Key只重新读取项目`.env`，不写进检查点，也不从系统环境回退。
- 恢复前检查agent/tools/main运行文件指纹、schema版本、任务目录、状态校验和、产物哈希。文件改写/删除/新增、损坏、不兼容或并发执行均拒绝，不覆盖原文件。代码版本更新后首版不迁移检查点。
- 进程锁由操作系统释放，不通过“删PID文件”判断恢复。停止标记使用独立控制锁，桌面恢复后新发出的停止请求不会在工作进程中被清除。
- 累计调用事件追加到原trace，恢复事件为run_resume；预算、审稿及重复保护不归零。原有token预算仍是软保护，SDK重试/未返回请求的账单不能由检查点精确推算。

JSON状态上限32MB，单产物20MB、总产物100MB、最多512文件；链接或越界产物不纳入可自动恢复任务。trace/messages和桌面控制文件不作产物哈希，执行状态、对话及用量由检查点保存，trace只作追加审计，不从任意日志猜出可运行状态。默认共享记忆库在任务目录外；若自定义记忆库放进任务目录，数据库变动可能触发哈希核对，首版不承诺自动协调该布局。

## 实施位置

- `agent/checkpoint.py`：事务快照、校验、资源界限、租约、状态序列化和会话恢复。
- `agent/loop.py`：模型返回落盘、工具批次/审稿边界、累计状态恢复、不确定结果停止。
- `main.py`：新任务碰撞保护、独立恢复入口、固定配置、本地收尾和记忆去重。
- `agent/resume.py`：status/stop/run CLI；`desktop_app`与前端接同一恢复路径。
