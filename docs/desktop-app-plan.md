# 本地桌面应用首版方案

用户选择独立桌面窗口。首版采用 Electron、React、TypeScript、Vite，Python FastAPI 服务复用现有研究入口；SQLite 保存会话和任务元数据。应用只监听回环地址，每轮研究独立进程运行，API Key 仍只从项目 `.env` 读取。

布局为左侧会话列表、中间聊天式研究过程、右侧报告/文件/证据/质量面板。显示真实工具和模型调用事件，不生成虚构进度或模型隐藏思考。首版实时展示执行事件，最终文本在研究完成后展示。

首版功能：新建、重命名、归档和搜索会话；提交研究与基于上一轮报告追问；单任务执行及等待队列；模型/步数/预算/历史记忆开关；协作停止和明确标记的强制停止；报告、CSV、图片与证据预览；真实审稿/证据状态；导入现有工作目录记录；桌面双击启动入口。

每轮研究保存自己的原问题、任务约定和产物。追问的历史报告作为带日期的数据提供，不能成为本轮指令或当前事实认证。关闭历史开关时不注入历史。查看已有任务不调用模型，重新执行明确新建运行并消耗新预算。

首版依赖本项目现有 `.venv`，部署到当前电脑并提供快捷启动入口。完整自包含安装包、跨电脑分发、自动升级、代码编辑器、多用户服务和系统自动化不属于本版。停止需要等待正在进行的模型/工具调用返回；强制停止保留已落盘内容并提示未完成。服务重启不自动恢复或重跑研究，真正检查点恢复仍属于阶段13。

验收：后端状态/队列/文件访问边界/密钥不出前端/取消与重启语义测试；前端构建；桌面启动与界面操作检查；真实研究完成后从界面打开报告和证据；关闭窗口后清理所属后端/工作进程；保持现有CLI兼容。交付运行命令、快捷入口和Git提交。界面上线不代替阶段12独立质量验收。
