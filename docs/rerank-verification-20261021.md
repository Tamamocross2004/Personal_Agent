# Cross-encoder 接入与实测（2026-10-21）

已接入硅基流动 `BAAI/bge-reranker-v2-m3`。当前默认关闭，可在桌面研究输入栏、知识库检索预览或 CLI 显式开启。本轮小资料对比没有观察到相关性指标提升，增加了延迟，因此不让日常查询默认承担新增开销。

## 实现

流程：关键词/向量独立召回 → RRF融合 → 默认取20个候选 → cross-encoder对问题与候选正文共同打分 → 选最终k个 → 有界补充相邻片段 → 原有证据与报告流程。

- `knowledge/reranking.py` 调用独立 `/rerank`，返回索引必须完整、唯一、不越界，分数须有限；允许负的logit，不强行解释成概率。
- 重排在最终top-k之前执行，原始片段ID、文件、页码、版本和文本区间保持绑定。参与评分的候选不因此全部登记为已读证据。
- 缓存键包括端点、模型、问题和有序候选文本哈希。更换重排模型不要求重建文档向量索引。
- 关键词模式不执行嵌入/重排；开启重排失败会报错，不自动重试或降级。需要原排序时必须显式关闭。
- 使用本项目 `.env` 的 `SILICONFLOW_API_KEY`；请求前后持久记录状态、用量、耗时、输入哈希、返回索引和分数。
- 嵌入、重排、聊天分别计量。重排输入/输出计入研究累计token和既有预算，用量不完整时停止为 `needs_verification`。未知用量不按零处理。
- 桌面研究与检索预览各有独立开关，研究中关闭后模型不能通过工具自行开启。配置与命令见 [RAG使用说明](rag-guide.md)。

接口依据：[硅基流动Rerank API](https://docs.siliconflow.cn/docs/api/rerank-post)。初始真实探测返回HTTP200、32个输入token、0个输出token；探测记录独立保留。

## 预定实测协议

资料与相关文档标注位于 `knowledge/rerank_cases.json`，在任何本轮付费对照前写入并保存到 `workspace/rerank-live-20261021/plan.json`。这是本代理设计的开发诊断，不是用户人工标注或独立保留集。

- 24份虚构园区制度资料，12个问题。10题有事实答案，2题要求资料未提供的补卡金额/维修时限。
- 每份资料本轮均为单片段，固定同一知识库代际；两臂使用相同问题、同一候选池、同样的top4口径。
- 关键词与向量分别召回；RRF保留前20候选，开启臂在此池上重排。没有改变嵌入模型、RRF公式或相关性标注。
- 查询嵌入预先缓存，两臂都命中同一查询缓存；每题两臂先后顺序由固定种子预先生成。计时包含当次Milvus访问、排序及开启臂的重排网络请求，不含准备阶段嵌入耗时。
- 每题开启臂首次重排均无缓存，另做一次重复查询验证缓存。全程不根据分数修改题目、标签、候选数、通过门槛或自动拒答阈值。
- 两道缺少金额/时限答案的问题不计入有答案题的相关性均值，但保留全部检索结果；它们仍可能返回可说明未知范围的原文。
- 额外以相同用户问题分别进行一次关闭/开启重排的真实研究，均15步、80000等效token、原有审稿上限。两轮模型独立运行，可自行选择检索词，不能把其总耗时差归因于重排单一因素。

## 检索结果

| 指标 | 关闭重排 | 开启重排 |
|---|---:|---:|
| Precision@4，10道可答题均值 | 42.5% | 42.5% |
| Recall@4，10道可答题均值 | 100% | 100% |
| MRR@4，10道可答题均值 | 1.000 | 1.000 |
| 单次检索平均耗时，12题 | 0.1592秒 | 4.6511秒 |

12题均保留完整排名、候选池、分数、命中正文和耗时。重排改变过候选次序和部分非标注片段，但预定三个相关性指标全部持平。原始召回已把可答题的目标文档放进top4且首项命中，存在明显天花板；本轮无法证明更大、更复杂资料上的重排收益，也不证明重排普遍无用。

12次检索重排合计 **18969输入token、0输出token**，API平均耗时约4.445秒。重复查询验证命中缓存，新增模型请求数为0。没有把高分解释为答案存在或低分解释为资料没有答案。

## 两轮真实研究

固定提问要求比较员工忘带卡、外来人员周末来访、机房准入及补卡费用。

| 记录 | 关闭重排 | 开启重排 |
|---|---:|---:|
| 正常结束 | `final_answer` | `final_answer` |
| Agent步数 | 4 | 5 |
| 聊天调用（含规划/审稿） | 6 | 7 |
| 本轮嵌入调用 | 4 | 3 |
| 本轮重排调用 | 0 | 4 |
| 研究总耗时 | 23.81秒 | 38.19秒 |
| 等效token，含检索模型用量 | 31148 | 29650 |
| 选定结论关联可定位 | 7项 | 6项 |
| 自动审稿记录 | `reviewed`，无问题项 | `reviewed`，无问题项 |

回看两份报告，主体手续与所给原文一致，均把补卡费用保留为未知，参考资料给出文件、页码和代际。关闭臂曾误用网页笔记工具，被既有来源守卫拒绝，之后自行完成报告；该错误记录没有删除。开启臂没有失败工具返回。

这是本代理的内容核对，不能标为用户人工复核。`mapped`只证明选定关联可定位；自动审稿无问题不认证全文事实正确。两轮检索词、调用次数、输出长度不同，等效token差值不能用于宣称重排节省费用或提高质量。
