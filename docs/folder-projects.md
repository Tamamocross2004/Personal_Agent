# 持续资料项目使用说明

重启桌面应用，进入“文件夹资料助手”，选择已授权资料目录，完成扫描与手动同步。展开 **持续资料项目（追问 / 修订 / 增量更新）**。

1. 填写项目名称、固定整理目标及结果字段，每行一个字段，点击 **创建资料项目（本地）**。项目针对整个已建库目录，首版最多12个字段，仍遵守原有50份文件及解析/索引容量限制。
2. 选择 **首次整理 / 增量更新**，核对“预计重新处理”的文件、保留批次数和服务；设置本次预算、输出和批数，点击 **执行项目操作**。这是显式模型操作，不会自动同步磁盘或增加预算。
3. 在“结果版本”查看本版结果、文件覆盖和来源引用。`structured`表示已解析范围有未截断的可用结构，不证明所有字段齐全或事实正确；失败或未读完保留为`partial`。必要时选 **继续上次未完成范围** 新建付费任务，继承原问题、索引和强度。
4. 用 **围绕本版继续追问** 提问。追问固定该版来源，重新检索后调用模型，不修改整理结果。可以切换历史版本后追问它；查看保存回答不重复调用模型。
5. 要改某些整理结果，选 **修订指定文件**，勾选文件并填写修订要求。新版本移出受影响旧批次，再按原文重新生成；未受影响结果保留。旧版本仍可查看和导出。
6. 磁盘资料变动后，先重新扫描并手动同步索引，再选 **首次整理 / 增量更新**。系统列出新增、变化、删除及尚未完成的文件。没有待处理文件时只保存本地版本，不调用模型。
7. 点击 **导出本版汇总结果（本地）**，得到摘要、CSV/XLSX对照表、来源清单和记录。它汇集可用原批次，不自动进行业务对象去重或跨文件合并。

## 哪些东西会保留

项目、设置、结果版和追问关联存在`workspace/folders/catalog.sqlite3`的新项目表中。原问答任务、索引代际、引用及旧导出继续保存。应用重启后可重新选择资料项目，不会自动重跑；当前浏览器会话内记住所选项目，扫描造成界面重新挂载时也会恢复选择。

每版保存目标/字段、设置版本、父版本、固定索引、来源文件SHA、批次引用和覆盖。文件内容未变时沿用原批次与原索引引用，不将旧引用伪装成新索引。来源变化或删除会将受影响旧批次从新结果移出；即使重处理失败，也不会拿旧值冒充新结果，可回看原版核对。

同一批结果若涉及多个文件，某个文件变化会使整批失效，依赖闭包内的其他文件也会重新处理。预览明确列出扩大后的范围。首版按文件SHA识别变化，并不分析业务对象“是不是同一个”。改目标或字段会使全部文件重新处理；只改名称不额外扩大范围。保存设置本身始终在本地完成。

历史结果与最近最多两轮同版问答放入有界背景，按约6000字符内容预算选择，省略数量保存在请求中；它们不是新证据，也不带来新的权限。所有新回答仍须引用本次实际送达的原句，使用原回答v3约定；不把历史模型文字升级为可信事实。

增量的“只处理变化文件”指新增证据与抽取批次范围；旧结果背景仍可能包含未变化文件的文字，并会发送给模型计费，不能理解为未变化资料的文字绝不重复传输。

## 成本、停止与并发

一个项目操作只启动一次既有分批问答任务。本次预算256至50000 Token、最多1至8批、每次输出128至4096（默认1200），还受项目单次上限和实际剩余预算限制。预计字段数来自用户字段列表，只参与分批估算，不保证模型完整遵守字段要求。思考强度可选，续读继承原任务设置。

点击操作前显示本地计划，启动时重新检查项目头版本、设置版本、来源和计划哈希。其他窗口更新了项目或同步改变了索引时，旧计划会被拒绝，刷新后再操作，不能覆盖新版本。同目录既有操作排队限制不放宽。

操作准备先写入本地记录，再启动付费任务。任务结束后刷新项目时，以本地事务生成一个新结果版；重复刷新不会再生成版本或重复调用。中断前未启动的准备会明确结束，不重发；已有任务继续按原中断策略保留。用量未知时拒绝直接续读，须先核对账单再决定新的修订。停止不能撤回在途请求或已经发生的费用。

追问也是单独的新请求，使用上方预算和输出设置。项目调用纳入既有文件夹调用统计；历史查看、预览、配置和导出不调用模型。未配置费率或用量缺失仍不记作零费用。

## 导出和能力边界

导出目录为`workspace/folders/project-outputs/<版本ID>/`，固定六个文件及一个哈希清单。再次导出校验并复用原文件，已修改或不完整的导出不会被覆盖。CSV保留公式前缀防护，XLSX固定文本单元格；未知、空白、零分别保留。每行标明原任务、批次、索引与源文件SHA，不因为汇总而更改对象名称、数值或单位。`record.json`保存版本及其各组原结构化答案与实际证据；完整原始模型响应继续保存在原任务记录中。

撤销授权后仍可看项目、版本和旧导出，新处理及追问被阻止。资料项目不修改源文件，不注册任意代码执行工具。不提供OCR、跨页表格恢复、任意段落文字编辑、自动业务关联、自动监控或后台定时执行。

项目工程交付不代表内容验收通过。阶段12未验收，所有结果仍为未正式审稿。真实小样例、失败日志及测试替身范围见[阶段25验证](stage25-verification-20261022.md)。
