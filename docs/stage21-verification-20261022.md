# 阶段21：日常操作体验

文件清单和已建库文件范围支持按文件名、格式和状态筛选；提问范围支持选择筛选结果及清空。筛选隐藏的已选文件仍显示在范围摘要中，索引版本改变时清空旧选择，不把新扫描文件混入旧索引。

桌面扫描改为本地后台任务，显示已发现项数（枚举前不知道总数，不编造百分比），可申请停止。停止不写入半份清单。建库显示当前解析文件、已完成文件数、嵌入与写入阶段；在途服务请求和当前最长20秒解析子进程结束后才能停止后续步骤。最近扫描与当前索引差异、未同步提示及回答固定版本同时可见；磁盘改动需要显式重新扫描，未增加自动付费同步。

用量只读合并索引事件和问答事件，以事件ID去重，包含CLI、检索预览、失败和中断调用。输入/输出Token为已知部分，未知用量单列。聊天按任务保存费率或当前配置参考费率估算；未配置嵌入/重排费率时总费用未知，不把它们记为零。估算不是账单，参考费率不是实时价格。
