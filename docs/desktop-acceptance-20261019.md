# 独立桌面首版验收 · 2026-10-19

按用户选择交付独立桌面窗口，技术栈与范围先记录在 [方案](desktop-app-plan.md)，使用见 [部署与操作说明](desktop-app.md)，结构化结果见 [验收记录](desktop-evaluation-20261019.json)。本次不是阶段12的新保留集验收，也未实现阶段13的检查点恢复，因此不将阶段14整体标为完成。

## 实现

- Electron 44.9.0 管理窗口、Python 服务和生命周期；React 19 + TypeScript + Vite 7 构建三栏界面，FastAPI + SQLite 管理会话、队列和文件访问。依赖版本由前端锁文件固定，本机 Node.js 为22.23.2，部署最低要求22.19。
- 新建、重命名、搜索和归档会话；提交研究或追问；配置模型、步数、等效 token 和历史背景；同一时间执行一项研究，其他排队。
- 中间展示实际事件与最终回答，右侧报告/CSV/图片、结论关联、原文摘录、审稿及版本状态；每轮保留自己的问题、约定、配置和产物。
- 使用现有项目 `.env` Key；前端不接收 Key。服务仅绑定回环地址，使用随机应用凭证、来源检查和有界文件访问。代码工具仍是现有本地执行能力，没有系统级沙箱。
- 正常停止在模型或工具边界生效，已返回的模型用量先计入 trace 和结果。强制停止终止所属工作进程树并提示不完整；关窗后清理所属服务，重启不重跑或恢复旧任务。
- 当前用户桌面快捷方式为 `Personal Agent.lnk`，项目安装及启动脚本可重新部署。依赖当前项目、`.venv` 与 Electron 运行时，不是自包含安装包。

## 检查

全量 Python 测试 **681 passed**，包括19项桌面接入测试，覆盖凭证、来源与密钥脱敏、文件越界/符号链接、单任务队列、停止和强制停止、故障队列、重启不续跑、缺失文件、SSE残行及超长事件、同会话历史与原问题约定。

`npm run build` 通过 TypeScript 检查及生产构建；`npm run smoke` 实际启动 Electron，完成新建、重命名、归档、搜索、设置与面板切换，不提交研究。现有真实结果的CSV、报告和证据抽屉均从界面打开；一张历史PNG经认证文件接口加载，尺寸为1050×630。未发现页面异常。读取及切换面板没有调用模型。

首次真实研究通过界面提交，配置 `deepseek-flash`、15步、80000等效token、关闭记忆。题目仅给定虚构价格与用量，要求Python计算、CSV、报告与依据：

| 项目 | 结果 |
|---|---|
| 执行 | `final_answer`，7步，33500等效token |
| CSV独立核算 | Alpha 0.48元，Beta 2.07元；Decimal独立计算一致 |
| 报告审稿 | 调用1次，当前版本 `reviewed`，0问题 |
| 关键结论 | 5条关联，`mapped`；仅认证结构定位 |
| 联网工具 | 0次 |
| 语义支持认证 | `not_certified`，不以模型审稿代替事实认证 |

另在最终接入路径上实际请求停止：模型调用返回后任务变为 `cancelled / interrupted`，保留751等效token、982原始token、0工具调用，没有把已消耗的调用清零，也未记为完成。排队取消另经界面验证，不调用模型。

界面导入20个已有顶层CLI任务；导入为只读索引，原报告和trace未重写。重启后能够查看刚才的报告、CSV和依据；关闭窗口后记录的两个服务进程均已退出。工作进程强制停止边界由假进程测试验证，没有向真实外部任务注入强杀。

开发中发现重命名后菜单没有收起，已修复并复检。最初停止适配器在模型返回后立即抛中断，会漏记该次用量；改为Agent原生的调用边界检查，先记账再中断，并有单测及上述真实停止验证。初期UI脚本还存在菜单定位和进程读取错误，已修正，最新只读操作检查通过。

## 保留边界

最终回答在研究结束后显示，执行事件实时更新；没有模拟token流。强制停止无法撤销已完成操作，也无法保证取得被中断API请求的用量。CSV限500行，文本预览限2MB，完整记录保留在任务目录。`skipped_limit`、`not_reviewed`、`stale` 与提前收尾分别显示，不能统一解释为成功。

没有复跑阶段11的42题真实矩阵；本次验证的是桌面接入与兼容性，一轮虚构价格研究不构成开放研究质量认证。完整质量保留集、累计预算恢复、自包含安装包及自动升级仍在后续范围。
