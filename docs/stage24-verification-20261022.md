# 阶段24：范围与完成状态的解释

本阶段提供只读范围视图、任务链和后续操作预览，不改变回答约定、答案校验、分批资源限制或旧任务。阶段12仍未验收；结构范围完整不证明内容抽取完整或语义正确。

## 已实现功能

- 桌面“范围与任务链”沿当前任务的前序回溯，按固定来源的主片段去重。区分无确认发送记录、发送结果未确认、已返回但响应未完成，以及有未截断的可用结构。
- 重做后保留历史失败，原失败任务与费用单列；附带上下文不重复计主片段，不混入其他续读分支。不把已有累计前缀数字当实际送达证据。
- 连续区间、真实页/行/单元格和块内字符位置分页查看；可从任务链回看前序原结果。缺失前序、循环、问题/固定范围不一致或片段不匹配时提示；回溯上限200个任务。
- 局部检索不计算全文阅读率，固定版本、已解析文字及OCR边界在界面和新导出中保持一致。结构状态来自已保存结果，不重新验证或改判旧回答。
- 普通继续与拆小重做显示待处理区间、预计首批、上下文位置、服务、模型、预算和输出空间；预览在本地完成，不新增付费请求。任务参数解析从原启动路径原样提取共用，AST核对原有规则一致，实际启动仍重新检查。
- 新导出保存范围与任务链快照，record.json原任务及CSV/XLSX比较行不被跨任务合成；已有导出按原清单复用。CLI增加scope只读查看。

## 验证与限制

专项检查覆盖分支隔离、按段去重、失败保留、未知送达、分页、缺失/循环/错误范围、首批预览一致、低预算时不预告付费发送、固定来源代际、撤销后只读、旧导出不升级，以及局部检索不计算全文阅读率。

隔离真实Electron流程验证设置、失败后范围解释、后续服务与范围预览、拆小重做、前序回看/返回最近任务、继续、导出及撤销后历史查看。使用新隔离目录和测试替身，只结束自己的测试进程。截图与日志使用stage24前缀，不覆盖既有阶段产物。
