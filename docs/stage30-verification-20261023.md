## 功能

全量整理可显式启用“持续整理至末尾”，使用1至64次模型调用上限，初始值16；普通模式仍是默认3批、最多8批。持续模式逐批扣减同一份总预算，默认预算10000、单次输出1200不变。到达读取末尾、调用上限、输出空间或总预算边界时结束；截断、无效结构/引用、未知用量、停止请求仍立即停止，没有自动重试、拆小、增加额度或修改答案。

桌面主提问、从旧短答创建全量整理、续读、预览和CLI共同保存参数。预览计划哈希包含运行方式和调用上限。修改设置须重新预览。CLI示例中的额度是用户显式设置，并非新默认：

```powershell
.\.venv\Scripts\python.exe -m folder_assistant ask <目录ID> "整理所选资料" --strategy exhaustive --read-to-end --max-calls 16 --budget 50000 --output-tokens 2400 --expected-fields 2
```

预算不足时仍可能部分完成，不能保证任意长资料在任意小预算内完整处理。字段正确性和输入送达分别判断。
